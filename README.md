# 🤟 AI Sign Language Translator

A real-time AI-powered Sign Language Translator that recognizes hand gestures from a webcam using a deep learning model and translates them into corresponding alphabet letters.

## 📌 Project Overview

This project was developed to explore the use of computer vision and deep learning for sign language recognition. It captures live video from a webcam, processes hand gestures, and predicts the corresponding alphabet using a trained neural network.

The project demonstrates practical applications of Python, TensorFlow, OpenCV, and JavaScript while promoting accessibility through AI.

---

## 🚀 Features

- Real-time hand gesture recognition
- AI model trained on the Sign Language MNIST dataset
- Live webcam prediction
- Interactive web interface
- Pre-trained model included
- Simple and easy-to-use interface

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/fariaaamir05/AI-Sign-Language-Translator.git
```

### 2. Navigate to the project folder

```bash
cd AI-Sign-Language-Translator
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Running the Project

### Train the model (Optional)

```bash
python train_model.py
```

### Start the application

Open `index.html` in your browser.

Allow camera permissions when prompted.

## 📊 Dataset

This project uses the **Sign Language MNIST Dataset**, which contains labeled images representing American Sign Language alphabet gestures.

Dataset:
https://www.kaggle.com/datasets/datamunge/sign-language-mnist
